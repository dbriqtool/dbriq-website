Install

  1. Right-click the downloaded ZIP and choose Extract All, then run dbriqSetup-1.0.0.exe from the extracted folder.
  2. Windows may say the publisher is unknown while dbriq is in beta: choose More info, then Run anyway.
  3. dbriq opens in your browser with demo data, so you can look around first.
  4. To monitor SQL Server you need Microsoft ODBC Driver 18 for SQL Server. The installer offers the download if it is missing.

Add your first server

  1. Run the matching setup script on the server: setup_monitoring_user.sql, setup_monitoring_postgres.sql or setup_monitoring_mysql.sql (Start menu > dbriq > Setup scripts). Each creates a read-only monitoring login.
  2. In dbriq, open Servers, choose Add server, enter the address and the monitoring login, then Test connection.
  3. Start with a non-production server while dbriq is in beta.
